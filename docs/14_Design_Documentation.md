## 3. Principles

- Trust-first visual language
- Role clarity via color coding
- Evidence by default (badges, status indicators)
- Mobile-first responsive behavior
- Nigeria-local context (Naira, local ID types)

## 4. Gestures and Interactions

- Pull-to-refresh on list pages
- Swipe actions on mobile for ticket/list items (planned)
- Optimistic UI on save/unsave and message send

## 5. Empty States

- Consistent empty states per feature module
- Illustration + headline + CTA
- Example: no listings, no applications, no tickets

## 6. Error States

- Inline validation errors on forms
- Toast for API failures
- Fallback UI for failed image loads
