# Technical Requirements Document (TRD)

## 1. Overview
PROPATI is a Next.js 14 property marketplace targeting the Nigerian market. It provides role‑based dashboards, 5‑layer verification, escrow payments via Paystack, and estate‑manager B2B tools.

## 4. Data Models (high‑level)
- **User** – Clerk ID, role, profile information.
- **Property** – title, address, price, images, verification status.
- **Transaction** – amount, status, escrow flag, Paystack IDs.
- **Agreement** – lease terms, digital signature, PDF reference.
- **Notification** – type, payload, read flag.

## 5. Scalability & Performance
- Server‑side rendering with ISR for public pages.
- TanStack Query caching on the client.
- Pagination on listing endpoints (cursor‑based).
- Rate limiting via Vercel Edge Middleware.
- Background workers (Node cron) for email and webhook retries.

## 6. Security
- JWT validation for API routes.
- Role‑based access control via Clerk middleware.
- CSP, XSS sanitisation, helmet‑style headers.
- HMAC‑SHA512 verification for Paystack webhooks.
- Auditable logs for verification steps (Prembly).

## 7. Deployment Strategy
1. **CI/CD** – GitHub Actions run `npm run lint && npm run typecheck && npm run test` on PRs.
2. **Vercel** – Automatic preview deployments for each branch.
3. **Database** – Supabase PostgreSQL; migrations via `prisma migrate`.
4. **Secrets** – Managed in Vercel env variables (Clerk, Paystack, Cloudinary, Prembly).
5. **Monitoring** – Sentry for error tracking, Vercel analytics for performance.
