# UI/UX Design Brief

## 🎨 Design Vision
PROPATI should feel **premium, trustworthy, and modern** while remaining highly usable on desktop and mobile devices. The visual language combines a dark‑mode friendly palette, subtle glass‑morphism, and smooth micro‑animations.

## 2. Component Guidelines
### Buttons
- Rounded corners: `0.5rem`.
- Primary: `background: var(--color-primary); color: #fff;` with subtle box‑shadow `0 2px 6px rgba(0,0,0,0.15)`.
- Hover: increase brightness `filter: brightness(1.1);` and translateY `-2px`.
- Disabled: `opacity: 0.4; cursor: not-allowed;`.

### Cards
- Background: `rgba(255,255,255,0.08)` (glass‑morphism) on dark mode, `#fff` on light mode.
- Border radius: `0.75rem`.
- Drop shadow: `0 4px 12px rgba(0,0,0,0.1)`.
- Padding: `var(--spacing-lg)`.

### Forms & Inputs
- Use **Radix UI** primitives with custom styling.
- Focus ring: `2px solid var(--color-primary)`.
- Error state: red border `hsl(0, 70%, 55%)` and inline message.

### Navigation
- Top bar with **notification bell** (see later implementation).
- Hamburger menu on mobile: 44 px tap target, slide‑in drawer with glass background.

## 4. Motion & Micro‑Interactions
- Use **CSS transitions** for hover/focus (0.2s ease).
- Use **Framer Motion** (or native CSS `@keyframes`) for page entry fades (`opacity 0→1`).
- Button press: scale to `0.97` for 100 ms.
- Drawer open/close: translateX from `-100%` to `0` with `cubic-bezier(0.25, 0.8, 0.25, 1)`.

---
## 5. Accessibility
- All interactive elements must have a minimum 44 px hit‑area.
- Contrast ratios >= 4.5:1 (WCAG AA).
- Keyboard navigation: focus order logical, focus visible.
- ARIA labels for icons (e.g., notification bell).
