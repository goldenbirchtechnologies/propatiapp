TECHNICAL NOTES
================================================================================
— Page keeps 'use client' (uses useState/useEffect for search, tabs, featured fetch).
— usePublicStats: fetch('/api/public/stats') on mount, setStats from d.listings.
  Returns null if no /listings.active in response or API fails — telemetry bar only
  renders when liveStats is truthy.
— useFeaturedFromDb: fetch('/api/listings?limit=6') on mount, filter out
  status suspended/deleted, map to card shape, slice 4 items.
  Falls back to featuredFallback (4 static cards) if API returns empty or errors.
— featuredFallback cards: feat-1..feat-4 with type (RESIDENTIAL/COMMERCIAL),
  kind (FOR SALE/FOR RENT/FOR LEASE), price, title, location, specs array,
  img URL, verified: true.
— FadeIn component: wraps cards with cn('fade-in-up', className) + animationDelay.
— cn() from @/lib/utils for all className composition.
— All internal links use <Link> from next/link.
— Search button onClick → router.push('/listings') — no setTimeout, no alert.
