## 3. Visual spec
- All cards: `glass-card` style — semi-transparent dark surface (`rgba(15,23,42,.6)`),
  border `1px solid rgba(255,255,255,.08)`, rounded `--radius-md`, `backdrop-blur`.
- Spacing: `gap-6` between the two columns, `space-y-6` between stacked cards.
- Inputs: dark bg, `1px solid rgba(255,255,255,.12)`, rounded `--radius-sm`,
  white placeholder at 50% opacity.
- Buttons: blue (`#3b82f6`) for primary, outline `1px solid #3b82f6` + white text +
  hover `bg-blue-500/10` for secondary.
- Badge pills: small, `rounded-full`, uppercase `text-xs`.
- Avatar: `96px`, `rounded-full`, border `2px solid rgba(255,255,255,.12)`.
- Avatar camera-fab: `28px` circle, bottom-0 / right-0, offset by +4px, dark surface
  + border, `shadow`.
